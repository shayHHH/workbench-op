# Bitvast Workbench 交易运营系统 Demo

一套纯 HTML、CSS、JavaScript 实现的 Bitvast 交易执行、客户准入与资金运营交互 Demo。无需安装依赖或构建。

## 运行

直接双击 `index.html`。如果浏览器限制本地脚本，也可以在当前目录执行：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

直接双击打开时，页面会使用随前端加载的压缩模板数据生成 PDF；通过 `http://127.0.0.1:4173/` 打开时则直接读取 PDF 模板。两种方式都会把已确认的表单字段写入生成结果。

## 推荐演示方式

1. 切换到 Operations Staff，进入“处理队列”查看八个业务状态。
2. 选择案件，演示补件、合规退回、银行提交、结果录入和业务终止。
3. 进入“交易流程”，按五条交易轨道演示 U换现金、现金换U、U换转账、转账换U、法币换法币。
4. 在顶部手动切换角色，查看各角色不同的导航、待办和数据范围。
5. 在“客户管理”查看主档和时间线，或使用“新建客户”建立一条独立草稿。
6. 点击左下角“重置演示数据”即可重新演示。

## 包含模块

- 访客/客户门户
- Agent 工作台
- 运营预审与案件队列
- 合规审核与风险提示
- 个人 KYC / 企业 KYB 客户主档
- 文件、OCR 与补件
- Agent / Sales 五步材料申报、OCR 可编辑表单与申请表 PDF 预览下载
- 现金、USDT 与外币库存预约与确认
- 银行水单、链上截图、现金信物与交易哈希凭证匹配
- 银行送审与结果回传
- 佣金计算与费率版本示意
- 角色权限、规则配置和审计日志

## 说明

- 所有数据只存在于浏览器内存，刷新后重置。
- 文件仅保存在当前浏览器会话的本地 Blob URL 中，不会上传到服务器。
- OCR、风险、库存、地址校验、手续费和佣金规则均为演示假设，不代表正式业务政策。

## 材料申报路径

- Agent / Sales 按材料项上传文件，上传完成后再选择 OCR 生成、手工填写生成，或不生成申请表直接送运营。
- 申请表使用 `assets/trustpass-stage1-template.pdf` 原始两页 TransferEasy 模板，通过本地 `pdf-lib` 填充。
- 生成路径要求下载未签署版、回传客户签署版后送审。
- 运营与合规共享同一材料目录，可逐项预览、下载、通过或退回。
- PDF 生成完成后自动打开统一预览弹窗，Agent、运营和合规均可在弹窗中查看并下载。
- 申请表编辑页支持登记财富/资金来源、交易目的、服务目的地、年度金额和单笔金额，并映射到原 PDF 对应复选框。
- “材料与补件”作为审核工单中心，只展示已发起工单；“发起审核”从客户管理选择客户，并按草稿、补件或只读详情恢复对应页面。
- 运营处理队列的八个状态均预置两条案例，便于演示不同客户类型、风险和终止来源。
