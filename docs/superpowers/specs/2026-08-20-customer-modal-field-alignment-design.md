# 客户新建弹窗字段调整

## 目标

减少中介下级客户编号区域的概念重复，并允许客户在创建时暂不分配所属交易员。

## 交互

- 直客和中介显示“客户编号”，系统预填 `20001-29999` 范围内的可用编号，用户可以修改。
- 中介下级客户显示“下级客户编号”，同一字段内提供“生成编号”复选框。
- 取消“生成编号”后禁用编号输入框，并允许以无编号状态创建。
- 所属交易员增加“不指定”选项，允许留空提交。
- 未指定交易员的客户在列表和时间线中显示“待分配”。

## 校验

- 需要编号时，编号必须是 `20001-29999` 范围内未被占用的五位数字。
- 不生成编号的中介下级客户跳过编号格式和占用校验。
- 客户名称仍为唯一必填的基础信息字段。

## 验证范围

- 三种客户类型切换后的字段标签和状态。
- 中介下级客户生成及不生成编号两种提交路径。
- 所属交易员为空时的创建结果。
- JavaScript 语法检查和弹窗可见状态检查。
